👩‍💼 Data Analytics in HR Dashboard

Overview

The Data Analytics in HR Dashboard provides a comprehensive view of workforce metrics, including hiring trends, employee distribution, and termination analysis. It is designed to support HR teams and management in making data-driven decisions for workforce planning and organizational growth.

✨ Features

Key Metrics

👥 Total Active Employees: 3,435

💰 Average Salary: 652,592

❌ Terminated Employees: 184

✅ Total Hired Employees: 3,619

Visual Insights

📊 Terminations by Year: Pie chart showing termination trends (2016–2024).

📈 Hires by Year: Line graph showing hiring growth from 2015–2023 with a slight dip in 2024.

🏢 Employees by Department: Bar chart comparing Finance, HR, IT, Marketing, Operations, and Sales (IT has the highest count).

🔵 Employee Titles (Bubble Chart): Visual distribution of roles such as Sales Executive, HR Manager, IT Manager, Data Analyst, Software Engineer, etc.

Interactive Filters

Department (Finance, HR, IT, Marketing, Operations, Sales)

Title (Accountant, Data Analyst, HR Manager, IT Manager, Software Engineer, etc.)

Year of Termination (2016–2024, Null)
